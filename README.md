# FlowCast

Planner per streamer Twitch. Tutto quello che serve per organizzare le dirette in un unico posto.

## 🌐 Usa l'app

**[stream-planner-omega.vercel.app](https://stream-planner-omega.vercel.app)** — funziona dal browser, niente da installare.

## Cosa fa

- **Calendario settimanale** per pianificare il palinsesto delle dirette.
- **Backlog giochi** con i titoli da giocare.
- **Recap delle stream** dopo ogni diretta.
- **Feed eventi live** collegato a Twitch.
- **Analytics** sull'andamento del canale.
- **Suggerimenti AI** basati sui trend di Twitch.

Interfaccia in italiano. Progetto in fase pre-lancio.
